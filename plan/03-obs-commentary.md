# 03. OBS 連動自動実況エージェント

## 1. 概要

OBS Studio と連携し、指定した映像リソースを監視して、その内容に対する実況を継続生成・読み上げするモード（UC-2）。

## 2. 前提

- OBS Studio が起動している。
- obs-websocket v5 が有効で、接続情報が Luna 設定に登録されている。
- 監視対象ソース（またはプログラム出力）が指定されている。

## 3. 機能要件

### F-OC-01 OBS 接続

- ホスト・ポート・パスワードで接続／切断できる。
- 接続状態を UI に表示する（接続中／切断／エラー）。
- 切断時は実況ループを停止する。

### F-OC-02 監視ソース選択

- 利用可能なシーン／ソース一覧を取得し、監視対象を選択できる。
- 監視対象は設定に永続化する。

### F-OC-03 フレーム取得

- 指定間隔（既定 3〜5 秒、設定可）でソースのスクリーンショット（画像）を取得する。
- 画像は LLM のマルチモーダル入力、またはキャプション前処理に渡す。
- Gemma 4 がビジョン非対応の構成の場合は、別途ビジョンモデル／キャプション手段を設定可能とする（フォールバック方針は `04-llm-integration.md`）。

### F-OC-04 実況生成

- 取得フレーム＋直近実況履歴から、短い実況文を生成する。
- 連続実況では重複・冗長を抑えるプロンプト制約を入れる。
- 実況言語は UI ロケールに従う（`ja` / `en`）。

### F-OC-05 実況出力

- 実況テキストを専用パネルに時系列表示する。
- VOICEVOX で読み上げる（キューイングし、重なりを制御）。
- アバターが発話に連動する。

### F-OC-06 実況制御

- 開始／一時停止／停止ができる。
- 一時停止中はフレーム取得と生成を止める。
- 「今すぐ実況」手動トリガーを提供する。

### F-OC-07 セーフティ

- 生成間隔の最小値を設け、LLM／TTS 過負荷を防ぐ。
- 1 回の実況文に最大文字数／トークン上限を設ける。
- 機密ソース名等をログに過剰出力しない。

## 4. 処理フロー

```
[実況開始]
  loop every intervalMs (until stop/pause):
    OBSClient.getSourceScreenshot(source)
      → CommentaryAgentService.buildPrompt(frame, history, locale)
      → LLMClient.generate
      → UI append commentary
      → VOICEVOX synthesize & enqueue play
      → AvatarBridge.emitSpeak(...)
```

## 5. OBS 連携詳細（想定 API）

obs-websocket v5 を利用する。

| 操作 | 用途 |
|------|------|
| `GetVersion` | 接続確認 |
| `GetSceneList` / `GetSceneItemList` | ソース列挙 |
| `GetSourceScreenshot` | 監視フレーム取得 |
| （任意）`GetCurrentProgramScene` | プログラム出力把握 |

接続パラメータ:

- `obs.host` 既定 `127.0.0.1`
- `obs.port` 既定 `4455`
- `obs.password`

## 6. 実況プロンプト方針（要約）

- 役割: 配信実況者として、画面上で起きていることを短く実況する。
- 制約: 1〜3 文、推測は明記、前回と同じ内容の繰り返し禁止、過度なフィラー禁止。
- 出力: 読み上げ用プレーンテキストのみ（マークダウン禁止）。

## 7. エラーハンドリング

| 状況 | 挙動 |
|------|------|
| OBS 未起動 | 接続エラー表示、実況開始不可 |
| ソース消失 | 警告表示、ループは維持しつつリトライ |
| LLM タイムアウト | 当該周期をスキップし、次周期へ |
| TTS キュー滞留 | 古いキューを破棄、最新実況を優先するオプション |

## 8. 受け入れ条件

1. OBS に接続し、ソース一覧から監視対象を選べる。
2. 実況開始後、定期的に実況文が生成・表示・読み上げされる。
3. 一時停止／再開／停止が正しく動作する。
4. OBS 切断時に例外で落ちず、状態が UI に反映される。
