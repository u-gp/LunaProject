# 00. プロダクト概要

## 1. 目的

**Luna** は、ローカル LLM（想定モデル: Gemma 4）を用いた Windows 向けエージェントアプリケーションである。  
ユーザーの調べ物・考察を対話で補助し、加えて OBS Studio と連携して映像リソースを監視しながら自動実況を行う。

## 2. 主なユースケース

### UC-1: デスクトップ常駐エージェント

- タスクトレイ／常駐ウィンドウとして動作する。
- テキスト入力、または音声入力で質問・相談を行う。
- エージェントが調査・考察を行い、テキストと音声（VOICEVOX）で返答する。
- 3D アバターが返答内容に連動して動作する。

### UC-2: OBS 連動自動実況エージェント

- OBS Studio の映像ソース（シーン／ソース）を監視する。
- 映像内容を継続的に解釈し、実況コメントを自動生成する。
- 実況はテキスト表示と VOICEVOX 音声で出力する。
- 3D アバターが実況発話に合わせてリップシンク／ジェスチャする。

## 3. 必須要件（概要）

| ID | 要件 |
|----|------|
| R-01 | Windows 向けネイティブ相当のデスクトップアプリとして提供する（軽量シェル。Electron は採用しない） |
| R-02 | ローカル LLM を利用する（クラウド必須依存なし）。想定モデルは Gemma 4 |
| R-03 | UI・エージェント応答は日本語・英語に対応する |
| R-04 | 音声入力（STT）が可能である |
| R-05 | AI 返答はテキスト＋VOICEVOX 音声で出力する |
| R-06 | FBX / VRM の 3D モデルを読み込み、発話に連動してアニメーションする |
| R-07 | OBS Studio と連携し、映像監視に基づく自動実況ができる |
| R-08 | 最終成果物を exe（インストーラ含む）としてビルドできる。アプリシェルは Tauri 2 |
| R-09 | ユニットテストを整備する |
| R-10 | プロジェクト構成・起動／ビルド／テスト手順を README に明記する |

## 4. 非目標（初期リリース外）

- macOS / Linux 向け配布（将来拡張は妨げない）
- クラウド LLM への必須依存（任意のフォールバックは別仕様とする）
- マルチユーザー同時セッション
- 商用配信向けの高度な権利管理・DRM
- モバイル対応

## 5. 用語定義

| 用語 | 意味 |
|------|------|
| エージェント | ユーザー入力または映像コンテキストを受け、LLM により応答を生成する制御主体 |
| デスクトップモード | UC-1 の常駐対話モード |
| 実況モード | UC-2 の OBS 連動自動実況モード |
| ローカル LLM | ユーザーマシン上（または LAN 内ローカルサーバー）で推論する LLM |
| VOICEVOX | ローカル音声合成エンジン（HTTP API 経由で利用） |
| アバター | FBX/VRM で読み込んだ 3D キャラクターモデル |
| OBS WebSocket | OBS Studio の外部制御・情報取得用プロトコル |

## 6. 成功基準（MVP）

1. デスクトップモードでテキスト／音声入力 → LLM 応答 → テキスト表示＋VOICEVOX 再生まで一連動作する。
2. 実況モードで OBS ソース画像を周期取得し、実況文を連続生成・読み上げできる。
3. VRM モデルを読み込み、発話中に口パク（最低限）が動作する。
4. `tools/test.bat` / `tools/debug.bat` / `tools/build.bat` でテスト・デバッグ起動・exe ビルドが可能。
5. 日本語 UI と英語 UI を切り替えられる。
