# 08. UI / アプリシェル

## 1. 概要

Tauri ウィンドウ、トレイ常駐、設定画面、モード切替 UI を定義する。

## 2. ウィンドウ

### F-UI-01 メインウィンドウ

- 既定サイズ: 1280×800（最小 960×600）。
- レイアウト（デスクトップモード）:
  - 左: アバタービュー
  - 右: チャット／実況パネル
  - 上部またはサイド: モード切替・設定入口

### F-UI-02 透過・配信向けオプション

- アバター領域の背景透過（任意設定）をサポートし、OBS でウィンドウキャプチャしやすくする。
- ウィンドウ全体の透過が必要な場合は Tauri の透明ウィンドウ設定を用いる（環境差分に注意）。

### F-UI-03 閉じる挙動

- ウィンドウ閉じる → トレイ常駐（既定）。
- 完全終了はトレイ「終了」。

## 3. トレイ

### F-TR-01 トレイメニュー

- ウィンドウを表示
- デスクトップモード
- 実況モード
- 設定
- 終了

### F-TR-02 通知

- 接続エラー等の重要イベントを OS 通知（過度に出さない）。
- Tauri の notification プラグイン、または相当 API を利用する。

## 4. 設定画面

必須設定カテゴリ:

| カテゴリ | 項目 |
|----------|------|
| 一般 | 言語、ホットキー、起動時モード |
| LLM | Base URL、モデル名、温度、タイムアウト |
| 音声 | STT エンジン、言語、VOICEVOX URL、話者 |
| OBS | ホスト、ポート、パスワード、監視ソース、間隔 |
| アバター | モデルパス、形式、背景 |

設定は保存ボタンまたは即時保存。不正値はバリデーションエラー。  
設定の永続化は Rust 側 `config` モジュールが担当する。

## 5. モード切替 UI

- `desktop` / `commentary` を明示切替。
- 切替確認（実況中など）を表示する。

## 6. アクセシビリティ（MVP 最小）

- 主要な操作がキーボードで到達可能。
- コントラストが極端に低くならないこと。

## 7. 受け入れ条件

1. トレイ常駐と再表示ができる。
2. 設定変更が永続化され、再起動後も有効。
3. モード切替で画面が切り替わる。
