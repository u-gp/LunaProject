# 07. 国際化（日本語・英語）

## 1. 概要

UI 文言およびエージェント応答言語として **日本語** と **英語** をサポートする。

## 2. 機能要件

### F-I18N-01 UI ロケール

- 設定で `ja` / `en` を切り替えられる。
- 切替は即時反映（再起動不要）を目標とする。
- OS ロケールから初回既定値を推定する（不明時は `ja`）。

### F-I18N-02 文言リソース

- `src/shared/i18n/locales/ja.json`
- `src/shared/i18n/locales/en.json`
- キー欠落時はキー名または英語フォールバックを表示し、開発時に警告ログを出す。

### F-I18N-03 エージェント言語

- システムプロンプトと「応答言語指示」をロケールに合わせる。
- STT 言語既定値をロケールに追従させる。
- VOICEVOX 話者は言語と独立（ユーザー選択）だが、英語読み上げ時の前処理ルールを適用する。

### F-I18N-04 日付・数値

- 必要箇所は `Intl` API でロケール整形する。

## 3. 対象範囲

| 対象 | 対応 |
|------|------|
| メニュー・設定・ボタン | 必須 |
| エラーメッセージ | 必須 |
| エージェント応答 | 必須（プロンプト制御） |
| ログ（開発者向け） | 英語固定で可 |

## 4. 受け入れ条件

1. UI を日本語／英語で切り替えられる。
2. 各言語でデスクトップ対話が成立する。
3. 実況モードの出力言語がロケールに一致する。
