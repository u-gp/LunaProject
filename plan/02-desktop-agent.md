# 02. デスクトップ常駐エージェント

## 1. 概要

デスクトップに常駐し、テキストまたは音声入力による調べ物・考察の対話補助を行うモード（UC-1）。

## 2. ユーザーストーリー

- 調べたいことを話しかけ／入力すると、ローカル LLM が回答し、テキストと音声で返る。
- 連続対話で文脈を維持した考察ができる。
- ウィンドウを閉じてもトレイ常駐し、ホットキーまたはトレイメニューから呼び出せる。

## 3. 機能要件

### F-DA-01 テキスト入力対話

- チャット入力欄からメッセージを送信できる。
- 送信後、ストリーミングまたは一括で応答テキストを表示する。
- 応答完了後、VOICEVOX で読み上げる（設定で無効化可）。

### F-DA-02 音声入力対話

- マイク入力を開始／停止できる（ボタンまたはプッシュトゥトーク）。
- STT 結果を入力欄に反映し、確認後送信、または自動送信（設定）する。
- 認識言語は UI ロケールに追従する（上書き可）。

### F-DA-03 会話コンテキスト

- 直近 N ターン（設定可能、既定 20）をコンテキストに含める。
- 「会話クリア」操作で履歴を破棄できる。
- システムプロンプトはロケールと用途（調べ物／考察）に応じて切り替える。

### F-DA-04 エージェント補助動作

- 調べ物: 事実整理・要点まとめ・追加確認質問を促す応答スタイル。
- 考察: 仮説列挙・賛否・次に考える観点の提示。
- ツール呼び出し（将来: ローカルファイル検索等）は本仕様の拡張ポイントとし、MVP では LLM 単体応答とする。

### F-DA-05 常駐動作

- 閉じる操作は「ウィンドウ非表示」を既定とし、アプリ終了はトレイメニューから行う。
- グローバルホットキー（設定可能）でウィンドウ表示／音声入力開始を行える。

### F-DA-06 アバター連動

- 応答テキスト／音声再生に合わせてアバターが発話アニメーションする。
- 詳細は [06-avatar-3d.md](./06-avatar-3d.md)。

## 4. 画面要素（MVP）

| 要素 | 説明 |
|------|------|
| 会話履歴 | ユーザー／アシスタントの吹き出し |
| 入力欄 | テキスト＋送信 |
| マイクボタン | STT 開始／停止 |
| 読み上げトグル | TTS ON/OFF |
| 会話クリア | 履歴削除 |
| アバタービュー | 3D モデル表示領域 |

## 5. 処理フロー

```
[ユーザー入力] → AgentOrchestrator
  → プロンプト組み立て（履歴＋システム）
  → LLMClient.generate / stream
  → 応答テキストを UI 反映
  → （TTS ON）VOICEVOXClient.synthesize → 再生
  → AvatarBridge.emitSpeak(text, audioTiming)
```

## 6. エラーハンドリング

| 状況 | 挙動 |
|------|------|
| LLM 未起動／接続失敗 | ユーザー向けエラーメッセージ＋再試行導線 |
| STT 失敗 | 入力欄にエラー表示、テキスト入力は継続可能 |
| VOICEVOX 失敗 | テキスト応答は表示し、音声のみ失敗通知 |
| 空入力 | 送信不可 |

## 7. 受け入れ条件

1. 日本語／英語それぞれで複数ターン対話ができる。
2. 音声入力 → テキスト化 → 応答 → 読み上げが通る。
3. トレイ常駐とウィンドウ再表示ができる。
4. LLM／VOICEVOX 停止時に致命的クラッシュせず、復旧手順が分かる。
